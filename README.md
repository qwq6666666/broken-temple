# 破廟宗主

純 HTML + CSS + ES Modules 的放置遊戲，不需打包。

## 執行
ES Modules 在 `file://` 會被瀏覽器擋，請用本機伺服器：

```bash
npx serve .
```

測試／調數值：網址加 `?speed=10`（遊戲時間 10 倍速）。Console 可用 `__game.state` 直接改資源。

```bash
node tests/run.mjs           # 核心邏輯測試（保底、成本、連鎖、tick 線性…）
node tests/sim.mjs 40       # 平衡模擬器：貪婪機器人跑 40 小時，印出各里程碑時間
node tests/sim.mjs 40 passive   # 同上但完全不打坐（純掛機）
node tests/sim.mjs 40 active rebirth   # 化神後自動轉生並購買道心，印出每一輪耗時
```

調數值時先跑 sim：目前節奏（機器人，偏樂觀）約為 首次引爆 15 分、煉氣九層 1.1 小時、化神 5.4 小時（含打坐）／9.7 小時（純掛機）。

## 結構
- `src/core/`：遊戲邏輯（零 DOM），`loop.js` 為固定 100ms tick（以時間差累積，背景分頁回來會補算）
- `src/ui/`：畫面與演出
- `src/data/`：建築、境界、弟子、仇人、台詞、法寶等資料
- `src/config.js`：所有平衡參數（成本係數、保底、蓄力、連鎖、訪客頻率、判定門檻…）

## 玩法重點（第二輪）
- **打坐**有 8 秒冷卻；建築等級上限受境界限制，成本隨解鎖境界縮放
- **存檔**：自動（每 10 秒／切分頁／關閉），可匯出入；**離線收益**最多 8 小時、50% 效率
- **亮一手**依「打不打得過」與仇人類型而變（當場打臉／逞強／得罪長老），**忍**有憋屈值；引爆前有預覽，弱勢長老會反噬
- **弟子特性**派駐才生效，碎片可升星（與築基以上突破共用）
- **宗門大事**與圖鑑：階段目標給招賢令、靈石與永久加成
- **內容量**：30 位弟子、18 則隨機事件、18 件功法法寶（含 5 件宿敵專屬）、7 種訪客性格、5 位宿敵
- **轉生與道心**：化神後可轉生（重置本輪、保留弟子收藏／法寶／大事／宿敵進度），依引爆、連鎖、宿敵、大事換道心，在「道心」分頁購買永久加成。轉生次數的自動加成前 10 次每次 +10%、之後每次 +1%（避免循環無限縮短）；商店買滿後可用道心兌換招賢令與碎片。公式在 `config.reincarnation`，商店在 `data/daoShop.js`
- **使用導引**：開場介紹、「❓ 說明」完整玩法（含所有新系統）、每個分頁第一次打開的簡短說明（可重設）、「💡 下一步」會依進度提醒故事、專精、秘境等
- **新手引導**：分頁依進度逐步解鎖、畫面上方「💡 下一步」提示（可關閉）、首次進入的開場說明與「❓ 說明」
- **手機版面**：≤860px 時標頭收小、分頁改成底部導覽列、全景縮小、觸控尺寸加大
- **宿敵劇情線**：5 位固定宿敵（錢貫→蕭承曜→柳玄素→雲渺子→玄機子），不能當場打臉，要留到引爆「碾壓」；各有專屬法寶，最後揭開破廟與老祖的來歷。內容在 `data/nemeses.js`
- **隨機事件**：每 7～14 分鐘彈出一則限時小抉擇（天降機緣、商隊求援、走火入魔…），資料在 `data/incidents.js`
- **秘境**：派 1～3 位弟子組隊限時探索（5 個秘境，專長／五行相合提高成功率，離線也會完成，領取獎勵）；**輪迴詞條**：轉生時可選一個有代價有報酬的詞條（苦行、貧道、盛世、隱世、天劫），本輪結算額外道心。資料在 `data/expeditions.js`、`data/mutators.js`
- **勢力與回頭客**：8 個勢力累積威望（三階：獎勵加成→更常求和→永久加成）；被碾壓的仇人日後會「回頭」——復仇者更強、獎勵 ×1.5，求和者帶賠禮可收下或拒絕。資料在 `data/factions.js`
- **建築專精與後期建築**：建築升到 Lv5 可二選一專精（本輪有效，轉生重選）；鎮魔塔（戰力、爆擊獎勵）、傳功殿（弟子等級上限與升級折扣）、靈獸園（招賢令增速、稀有事件）依境界解鎖。資料在 `data/specs.js`、`data/buildings.js`
- **弟子故事與緣分**：30 位弟子各有機緣故事（Lv5 解鎖第一章，SR 以上升星解鎖第二章），讀完特性永久 +10%；12 組緣分（兩人派駐同一建築即加成）。文字在 `data/stories.js`、`data/bonds.js`
- **宗門全景**：水墨山水 SVG 場景——6 棟建築各有 5 階段簡約剪影（隨等級換造型），背景隨境界變化（荒山→雲海→浮島→極光→天門與星空），弟子站在派駐的建築旁，訪客走進山門；點畫面上的建築可直接查看與升級。造型在 `src/ui/sceneArt.js`
- **動畫**（Canvas 粒子 + CSS）：全景靈氣光點、晝夜光影、建築微動（丹房冒煙、靈田搖曳、大陣光環）、升級彈跳迸發、打坐靈氣匯聚、資源跳動飄字、按鈕水波紋、抽卡封印光柱與翻牌（SSR/UR 另有光芒）、訪客與事件進場／離場殘影、宿敵來訪的紅色暈影。可用頁首「動態」鈕關閉
- **音效**為程式即時合成（Web Audio，零音檔），頁首可靜音；引爆有兩段式台詞、震動、粒子、連鎖橫幅（可切換「減少動態效果」）
