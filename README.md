# 破廟宗主

純 HTML + CSS + ES Modules 的放置遊戲，不需打包。

## 執行
ES Modules 在 `file://` 會被瀏覽器擋，請用本機伺服器：

```bash
npx serve .
```

測試／調數值：網址加 `?speed=10`（遊戲時間 10 倍速）。Console 可用 `__game.state` 直接改資源。

```bash
node tests/run.mjs           # 核心邏輯測試（保底、成本、連鎖、tick 線性…）
node tests/sim.mjs 40       # 平衡模擬器：貪婪機器人跑 40 小時，印出各里程碑時間
node tests/sim.mjs 40 passive   # 同上但完全不打坐（純掛機）
node tests/sim.mjs 40 active rebirth   # 化神後自動轉生並購買道心，印出每一輪耗時
node tests/sim.mjs 12 equip branch commission   # 開啟新功能的最佳化機器人（自動裝備法寶、弟子進階、領委託）
```

調數值時先跑 sim。單一亂數種子結果雜訊很大（同設定化神耗時可差 ±20%），比較設定請多種子取平均。
目前節奏（16 種子平均，機器人偏樂觀）：首次引爆約 15 分，首輪到化神約 **4.1 小時**（含打坐）／**4.3 小時**（純掛機）；之後每輪轉生約 2 小時、道心約 50。
新功能對首輪到化神的影響（含打坐，最佳化機器人上限）：法寶裝備 −2%、弟子進階 −3%、宗門委託 −7%，全開約 −15%；純掛機全開約 −8%。
宗門委託對平衡很敏感：早期靈石獎勵下限（`stoneMin`）若設 20（早期突破只要 4 靈石），化神會快 13～19%，現為 4。
